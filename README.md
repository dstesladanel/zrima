# זרימה · Zrima

מערכת ניהול תורים חיה לעסקי שירות קטנים (בונות ציפורניים, ספרים, קוסמטיקאיות…). מימוש MVP (גרסה 1) של מסמך ה־PRD.
עברית / RTL. **בלי תלויות בזמן ריצה.** רץ בחינם על Cloudflare, ואפשר להריץ גם מקומית עם Node.

## פריסה בחינם (Cloudflare, בלי כרטיס אשראי)

מה מקבלים בחינם: שרת שלא נרדם, נתונים שנשמרים, תזכורות שרצות אוטומטית כל דקה, כתובת HTTPS.

1. פותחים חשבון חינם ב־**dash.cloudflare.com** (מייל וסיסמה).
2. **Workers & Pages ← Create ← Import a repository** ← מתחברים ל־GitHub ובוחרים את `zrima`.
   בהגדרות הבנייה משאירים את ברירות המחדל (Deploy command: `npx wrangler deploy`) ולוחצים Deploy.
3. אחרי הפריסה: **Settings ← Variables and Secrets** ← מוסיפים:
   | שם | ערך |
   |---|---|
   | `OWNER_KEY` | (Secret) מפתח כניסה לניהול, לפחות 12 תווים. שמרו אותו |
   | `BOOTSTRAP_SLUG` | הכתובת של העסק, באנגלית: `noa` |
   | `BOOTSTRAP_NAME` | שם העסק |
4. נכנסים ל־`https://<השם-שלכם>.workers.dev/admin` עם המפתח. עמוד ההזמנה: `/b/noa`, לוח חי: `/live/noa`.

### ניהול כללי (כל העסקים)
- **מסך:** `/platform`, כניסה עם `MASTER_KEY` (מגדירים פעם אחת: `npx wrangler secret put MASTER_KEY`). רשימת עסקים עם מספרים בלבד (בלי שמות וטלפונים של לקוחות), יצירת עסק חדש (נוצר מפתח כניסה שמוצג פעם אחת), מפתח כניסה חדש בלחיצה וטעינת הגדרות מוכנות.
- **טרמינל:** `node scripts/create-business.js <אתר> examples/<קובץ>.json [--update | --reset-key]`.
- שלושה מפתחות שונים: `OWNER_KEY` נכנס לעסק אחד (`/admin`), `MASTER_KEY` מנהל את כל העסקים (`/platform`), והכניסה ל־Cloudflare מנהלת את האתר עצמו.

### וואטסאפ בחינם
בלי API בתשלום: כל הודעה שהמערכת רוצה לשלוח (אישור, תזכורת, עיכוב) נכנסת ל**תור שליחה**. בעל העסק לוחץ "שליחה בוואטסאפ", נפתחת שיחה עם ההודעה מוכנה, ולוחץ "שלח". אין צורך בחשבון עסקי ובאישורי Meta.
אם יש WhatsApp Cloud API, מגדירים `WHATSAPP_TOKEN` ו־`WHATSAPP_PHONE_ID` וההודעות יישלחו אוטומטית.

### מגבלות החינם (לפי הידוע לי, כדאי לוודא באתר Cloudflare)
כ־100 אלף בקשות ביום לכל החשבון. המערכת חוסכת: מסך הניהול שולח בקשה אחת כל 10 שניות ולא שולח כשהלשונית מוסתרת, ולקוחות בודקים כל 12–15 שניות. קבצי האתר עצמם לא נספרים. מספיק לכמה עסקים קטנים.

## הרצה מקומית

```bash
node seed.js          # עסק דמו (מפתח: demo-owner-key)
node server.js        # http://localhost:3000
npm test              # 17 בדיקות לחוקי המוצר
npm install && npm run cf:dev   # אותה מערכת על סביבת Cloudflare מקומית
```

| כתובת | מי |
|---|---|
| `/admin` | בעל העסק: היום החי, שבוע, לקוחות, שירותים ושעות, הודעות ומבצעים, המתנה, מותג, מדיניות, מדדים |
| `/b/<slug>` | עמוד הזמנה ממותג (לביו באינסטגרם / QR) |
| `/t/<token>` | "התור שלי": סטטוס חי, אני בדרך / מאחר/ת / לא מגיע/ה, הזזה, ביטול |
| `/live/<slug>` | לוח סטטוס חי אנונימי |
| `/w/<token>` | תפיסת מקום שהתפנה (מרשימת המתנה) |
| `/o/<token>` | הסרה משיווק |

חלופות פריסה (בתשלום קטן): `Dockerfile` ו־`render.yaml` לשרת עם דיסק קבוע.

## איך זה בנוי
- `lib/engine.js` — כל חוקי המוצר (זמינות, רצפה, עיכובים, חורים, שיווק). `lib/routes.js` — ה־API, בלי תלות בסביבה.
- `server.js` — מתאם ל־Node. `worker/` — מתאם ל־Cloudflare: קבצים סטטיים מ־`public/`, אובייקט Durable Object אחד עם SQLite שמחזיק את הנתונים (חוט אחד, בלי מרוצי נתונים), ו־cron של דקה לתזכורות.

## מה ממומש מה־PRD

- **מותג אישי** (§6): לוגו, צבעים, גופן מרשימה, טון פנייה (נקבה / זכר / ניטרלי), שם העסק בראש כל הודעה.
- **הזמנה** (§7): זמינות לפי משך + באפר, שעות וחריגים, lead time, חלון קדימה, ביטול/הזזה עצמית עד Y שעות, זיהוי לקוח חוזר לפי טלפון.
- **רצפה חיה** (§8): הגיע ≠ התחיל; טיימר מתחיל רק ב"התחיל טיפול"; הארכות +5/+10/+15 עם תקרה 20; דחיפת התורים הבאים תוך ספיגה בבאפר; Walk-in; הפסקה.
- **כלל הזהב**: כל שינוי בשעת כניסה של לקוח אחר יוצר הודעת תפעול (קל ≤7, ברור 8–15, מעל 15 באישור בעל העסק).
- **לוח חי** (§9): אנונימי (נבדק אוטומטית), זמן בקפיצות של 5 דקות.
- **הודעות** (§10): שני צינורות נפרדים; שיווק ידני רק למי שהסכים, מגבלת תדירות, קישור הסרה בכל הודעה.
- **אריזת היום** (§11): הצעות בלבד לאישור. אין הזזה אוטומטית.
- **כרטיס לקוח, רשימת המתנה, מדדים** (§13, §14, §17).

## החלטות איפה שה־PRD פתוח (§19)
"אני בדרך" רק מודיע. ביטול באיחור בלי תשלום. הלוח הכללי פתוח לכל מי שיש לו קישור. כמה כיסאות = נותני שירות נפרדים. ניסוח עיכוב קצר וחם.

## לא בגרסה הזאת
SMS, פקדון, קופה, דומיין עצמי, חיבור OAuth/OTP לבעל העסק (כרגע מפתח יחיד), תבניות וואטסאפ מאושרות.
